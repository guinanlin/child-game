# 过桥小勇士 (Go Through The Bridge)

一款轻量的休闲物理小游戏：按住以伸长木棍，松开让木棍翻转搭桥，连接下一座平台前进。命中平台中央“完美区域”可获得双倍得分。支持桌面与移动端，全屏自适应，并带有背景音乐与音乐开关按钮。

## 玩法简介

- 按住鼠标/触屏：木棍随时间增长
- 松开：木棍旋转 90° 充当桥梁
- 成功到达下一平台：+1 分；命中平台中央“完美区域”：+2 分（出现“双倍得分”提示）
- 角色掉落：本局结束，点击“再来一次”重新开始
- 快捷键：按空格可快速重开
- 背景音乐：左上角按钮可在“🔊/🔇”之间切换

## 本地运行

方式一：直接打开

1. 双击 `index.html` 即可在浏览器中运行
2. 首次点击/触摸/按键后，浏览器会允许播放背景音乐（受浏览器自动播放策略影响）

方式二：启动本地静态服务器（推荐）

```bash
# 任一其一即可
npx serve . --yes
# 或
python -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`（或命令行提示的地址）。

## 文件结构

```
.
├── index.html   # 页面结构与元素（标题、分数、画布、提示、按钮、音乐等）

└── README.md    # 本说明文档
```

## 操作与控件

- 鼠标/触控：按住伸长木棍，松开搭桥
- 空格键：快速重开
- 左上角按钮：切换音乐静音与取消静音（图标在“🔊/🔇”间切换）
- 右上角：实时分数

## 自定义与调整

样式与布局（`style.css`）

- 可修改主题色、阴影、圆角、按钮位置等（如 `#audio-toggle` 的 `top/left`）

难度与参数（`script.js`）

- 可调整以下常量来改变手感/难度：
  - `stretchingSpeed`、`turningSpeed`、`walkingSpeed`、`transitioningSpeed`、`fallingSpeed`
  - 平台间距与宽度生成逻辑（`generatePlatform` 中的最小/最大间距与宽度）
  - 完美得分区域大小：`perfectAreaSize`

音频与提示文案

- 背景音乐音量由 `bgm.volume = 0.5` 控制，可自行调整
- 更换 `bg.mp3` 即可替换背景音乐
- 页面文本（标题、提示、按钮）在 `index.html` 中可直接修改

## 兼容性与注意事项

- 画布全屏自适应窗口大小，窗口变化时会重新绘制
- 移动端默认使用被动监听以保证滚动/触控性能
- 浏览器自动播放策略可能阻止未交互时的音频播放，首次点击/触摸/按键后即可正常播放
